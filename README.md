# Be My Date? 💌

A one-file (`index.html`) date invitation: "Will you go on a date with me?", then pick a place, pick activities, pick a time, and the answers are emailed to you.

## Setup

1. Open `index.html` and replace `EMAIL` with your email address.
2. Turn on GitHub Pages (Settings → Pages → branch `main`).
3. Send one test answer yourself. FormSubmit emails you an activation link: click it once.
4. After that, every answer lands in your inbox (check Spam too).
